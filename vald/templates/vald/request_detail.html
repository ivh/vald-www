{% if converters %} {% comment %} Converting a large result takes tens of seconds, during which a plain form submit shows nothing at all - so the button says so, and refuses a second click that would only queue the same work again. A download fires no event the page can see, so the button cannot know when to come back on its own. The form sends a one-shot token, the download response returns it as a cookie, and this watches for it. If that never arrives - the conversion failed, the user cancelled the save dialog - the button comes back anyway after a while rather than staying dead. {% endcomment %} {% endif %} {% if req.is_pending %} {% comment %} Replaces a meta refresh that reloaded the page every ten seconds regardless of what the reader was doing. This asks a small JSON endpoint instead and reloads once, when the job is actually no longer pending; while it waits it keeps the queue position current in place. The interval backs off, because most of these finish in the first half-minute and the ones that do not can be checked less often. {% endcomment %} {% endif %} {% endblock %}
